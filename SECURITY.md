# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, credentials, personal data, or internal infrastructure information.

Include the affected version, reproduction steps, security impact, and any suggested mitigation. Reports will be acknowledged and triaged before public disclosure.

## Supported versions

Only the latest revision on the default branch is supported.

## Demonstration scope

SecureFlow is a portfolio reference implementation, not a hosted production service. The identity provider, durable persistence, secret storage, telemetry, infrastructure controls, and operational response process belong to the deployment environment.
